# InterviewAI Frontend

This is the ready-to-run React + Tailwind CSS frontend designed to connect with your Spring Boot backend (
`com.interviewAi.Backend`).

## Quick Start (3 Steps)

1. Extract this zip file:
   ```bash
   cd interview-ai-frontend
   npm install
   ```

2. Run development server:
   ```bash
   npm run dev
   ```
   Opens on: http://localhost:5173

3. Ensure Spring Boot is running on `http://localhost:8080` and has CORS configured.
